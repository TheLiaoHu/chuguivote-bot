# State flag assets

These 51 SVGs (50 states and D.C.) contain the static SVG artwork distributed in `us-state-flags` 1.0.7 (ISC license metadata), https://www.npmjs.com/package/us-state-flags. The React wrapper was removed; no runtime dependency is required. Package SHA-512 integrity was checked against npm registry metadata before extraction. Assets are served locally so flag backgrounds also work without third-party requests.
